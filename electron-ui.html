💾 Manual Backup System

The CafePOSPro system includes a built-in backup feature to protect your business data:

  • Create Backups: Click "Create Backup" to save your current data
  • Backup Location: Choose where to save your backup files
  • Backup Format: Standard SQL format compatible with PostgreSQL
  • Restore Data: Use PostgreSQL tools to restore from backup files

When to Create Backups:

  • Daily at the end of business
  • Before major system changes
  • After adding significant inventory
  • Weekly for long-term archival

🏆 Backup Best Practices

  • 3-2-1 Rule: Keep 3 copies of your data (1 primary + 2 backups), on 2 different media, with 1 offsite
  • Automate When Possible: Scheduled backups run automatically (see schedule above)
  • Test Restores: Periodically verify your backups can be restored
  • Encrypt Sensitive Data: Protect backup files with encryption
  • Version Your Backups: Keep multiple versions with dates
  • Monitor Backup Success: Check logs to ensure backups complete successfully
  • Store Securely: Keep backups in fireproof safes or cloud storage

📊 Storage & Limits

Free Plan Storage: 1GB database storage (more than enough for most cafes)

Typical Cafe Usage: ~20-30MB per month for orders, inventory, and staff data

Time to Reach Limit: 30+ months for average cafe usage

What Counts: Database records and uploaded images

What Doesn't Count: Application code and frontend assets

Warning System: You'll receive email alerts at 80% and 95% usage

Solutions if Approaching Limit:

  • Export and archive old data
  • Compress images before upload
  • Upgrade to paid plan ($19/month for 10GB)
