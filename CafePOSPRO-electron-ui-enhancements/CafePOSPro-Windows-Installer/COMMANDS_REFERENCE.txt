# CafePOSPro Technical Commands Quick Reference

## Essential Convex Commands

### Authentication Setup
```bash
# Configure authentication for deployment
npx @convex-dev/auth

# This generates JWT keys and updates configuration files
```

### Development Server
```bash
# Start development server with network access
npm run dev

# The server will be accessible at:
# - Local: http://localhost:5173
# - Network: http://YOUR_LOCAL_IP:5173
```

### Deployment
```bash
# Login to Convex (if not already logged in)
npx convex login

# Deploy to staging environment
npx convex deploy

# Deploy to production environment
npx convex deploy --prod
```

### Environment Management
```bash
# Set environment variables
npx convex env set VARIABLE_NAME value

# List environment variables
npx convex env list

# Remove environment variable
npx convex env remove VARIABLE_NAME
```

## Database Operations

### Data Export/Import
```bash
# Export data to backup file
npx convex export --file=backup.zip

# Import data from backup file
npx convex import backup.zip
```

### Running Functions
```bash
# Run a specific function
npx convex run functionName

# Run function with arguments
npx convex run functionName '{"arg1": "value1", "arg2": "value2"}'
```

## Multi-Terminal Configuration Commands

### Network Setup
```bash
# Find local IP address (Windows)
ipconfig

# Find local IP address (macOS/Linux)
ifconfig

# Check if port is in use
netstat -an | find "5173"  # Windows
lsof -i :5173              # macOS/Linux
```

### Firewall Configuration (Windows)
```bash
# Allow port 5173 through Windows Firewall
netsh advfirewall firewall add rule name="CafePOSPro" dir=in action=allow protocol=TCP localport=5173
```

## Environment Variables Required

### Development
```
JWT_PRIVATE_KEY=your_generated_private_key
SITE_URL=http://localhost:5173
DEV_URL=http://localhost:5173
```

### Production
```
JWT_PRIVATE_KEY=your_generated_private_key
SITE_URL=https://your-project-name.convex.cloud
```

## Common File Locations

### Configuration Files
- `convex.json` - Project configuration
- `vite.config.ts` - Development server configuration
- `.env.local` - Local environment variables (generated by auth setup)

### Important Directories
- `convex/` - Backend functions and schema
- `src/` - Frontend source code
- `docs/` - Documentation files
- `scripts/` - Utility scripts

## Troubleshooting Commands

### Check Installation
```bash
# Verify Node.js installation
node --version
npm --version

# Check dependencies
npm list
```

### Reset Development Environment
```bash
# Clear node_modules and reinstall
rm -rf node_modules package-lock.json  # macOS/Linux
rmdir /s node_modules                  # Windows
npm install
```

### View Logs
```bash
# View Convex function logs
npx convex logs

# View development server logs
# Check terminal where npm run dev is running
```

## Backup and Maintenance

### Create Backup
```bash
# Using built-in script
npm run db:backup

# Using Convex export
npx convex export --file=backup-$(date +%Y%m%d).zip
```

### Update Application
```bash
# Pull latest changes
git pull origin main

# Update dependencies
npm install

# Redeploy
npx convex deploy
```
