# CafePOSPro - Complete Café Management System (Customer Package)

## Welcome!

This package contains all the files you need to install and run CafePOSPro, a complete café management system. Follow the setup guide to get started.

## Package Contents

- `src/` - Frontend source code
- `convex/` - Backend functions and database schema
- `scripts/` - Utility scripts for backup, setup, and maintenance
- `docs/` - Documentation files
- `CUSTOMER_SETUP_GUIDE.md` - Step-by-step installation instructions

## Quick Start

1. Install Node.js (version 16 or higher) from https://nodejs.org/
2. Create a free Convex account at https://dashboard.convex.dev
3. Follow the instructions in `CUSTOMER_SETUP_GUIDE.md`

## System Requirements

- Node.js 16+
- Internet connection
- Modern web browser (Chrome, Firefox, Safari, Edge)
