## Overview

CafePOSPro is a comprehensive café management system designed to streamline operations for restaurants and cafés. The system provides features for self-service ordering, staff management, inventory control, order processing, and financial reporting.

Key features include:

- Customer self-service ordering via QR codes
- Real-time order tracking and status updates
- Staff management with role-based access control
- Inventory management with low stock alerts
- Kitchen order management system
- Cashier payment processing
- Financial reporting and analytics
- Table management system
- **Customer feedback collection and management**

## System Architecture

The application follows a modern web architecture with a clear separation of concerns:

```

└─────────────────┘    └──────────────────┘    └─────────────────┘
       │                        │                        │

┌─────────────────┐    ┌──────────────────┐    ┌─────────────────┐
│  Electron App   │    │  Authentication  │    │   Drizzle ORM   │
│  (Desktop UI)   │    │  (Convex Auth)   │    │   (Migrations)  │

```

## Installation & Setup

### Prerequisites

1. Node.js (v16 or higher)
2. npm (v8 or higher)
3. PostgreSQL database
4. Convex account

### Setup Steps

1. **Clone the repository:**

```bash
git clone <repository-url>
cd cafepospro
```

2. **Install dependencies:**

```bash
npm install
```

3. **Set up environment variables:**
   Create a `.env.local` file with the following:

```env
# Convex deployment (generated by convex dev)
CONVEX_DEPLOYMENT=your_deployment_url
VITE_CONVEX_URL=your_convex_url

# Database connection
DATABASE_URL=postgresql://username:password@localhost:5432/cafepospro
```

4. **Initialize the database:**

```bash
npm run db:setup
npm run db:seed
```

5. **Start the development server:**

```bash
npm run dev
```

6. **Access the application:**
   Open your browser to `http://localhost:5173`

## Core Features

### 1. Customer Self-Service Ordering

Customers can scan QR codes at their tables to access the self-service ordering system:

- Enter name for order attribution
- Browse menu with category filtering
- Add items to cart with quantity adjustment
- Add special cooking instructions per item
- Submit orders for kitchen preparation
- Track order status in real-time
- View order history at their table
- **Provide feedback after leaving the table**

### 2. Staff Management

Role-based access control for different staff members:

- **Manager:** Full system access
- **Cashier:** Order completion and payment processing
- **Waiter:** Order taking and table management
- **Kitchen:** Order preparation and status updates

### 3. Inventory Management

- Track stock levels for all menu items
- Set low stock threshold alerts
- Update inventory quantities
- Manage suppliers and product information
- Receive low stock notifications

### 4. Order Management

- Real-time order tracking
- Status updates (pending, preparing, ready, served)
- Order history and reporting
- Payment processing
- Table order clearing

### 5. Kitchen Management

- View pending orders
- Update item statuses
- Receive notifications for new orders
- Track preparation progress

### 6. Financial Reporting

- Sales reports
- Inventory reports
- Staff reports
- Ledger management
- Tax calculations

### 7. Table Management

- Table status tracking (available, occupied, reserved)
- QR code generation for table access
- Table order history
- Table clearing functionality

### 8. Feedback Management

- **Customer feedback collection**
- **Rating system (1-5 stars)**

## Deployment

### Development Deployment

1. Run `npx convex dev` to provision a development deployment
2. The deployment URL will be saved to `.env.local`

### Production Deployment

1. Run `npx convex deploy` to deploy to Convex cloud
2. This creates a permanent deployment URL for production use

### Building for Production

1. Run `npm run build` to generate production-ready files
2. Output files are placed in the `dist` directory
3. Deploy the contents of `dist` to your web server

### Database Deployment

1. Ensure PostgreSQL is running
2. Set the `DATABASE_URL` environment variable
3. Run `npm run db:setup` to initialize the database
4. Run `npm run db:seed` to populate with initial data

## Troubleshooting

### Common Issues

1. **Server fails to start**

   - Check that all required environment variables are set
   - Ensure PostgreSQL is running and accessible
   - Verify Convex credentials

2. **Database connection errors**

   - Verify `DATABASE_URL` is correct
   - Check PostgreSQL service status
   - Ensure database user has proper permissions

3. **Authentication issues**

   - Verify admin credentials
   - Check Convex authentication configuration
   - Ensure network connectivity to Convex servers

4. **Real-time updates not working**
   - Check Convex connection
   - Verify subscription queries
   - Ensure proper WebSocket support

### Useful Commands

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run db:test` - Test database connection
- `npm run db:seed` - Seed database with initial data

- `npx convex dev` - Start Convex development server
